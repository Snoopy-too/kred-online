# KRED Internationalization (i18n)

## Quick Reference

### Import & Basic Usage
```tsx
import { useTranslation } from 'react-i18next';

const { t } = useTranslation('common');
<button>{t('actions.play')}</button>
```

### Common Translation Keys

**Actions:** `actions.play`, `actions.pass`, `actions.challenge`, `actions.accept`, `actions.confirm`, `actions.cancel`  
**Pieces:** `pieces.pawn`, `pieces.heel`, `pieces.mark`  
**Locations:** `locations.office`, `locations.rostrum`, `locations.seat`  
**Phases:** `phases.campaign`, `phases.bureaucracy`, `phases.challenge`, `phases.drafting`  
**UI:** `ui.player`, `ui.turn`, `ui.credibility`, `ui.funding`

### Change Language
```tsx
const { i18n } = useTranslation();
i18n.changeLanguage('es'); // Spanish
i18n.changeLanguage('en'); // English
```

---

## Overview

KRED supports multiple languages using **react-i18next**:
- 🇺🇸 **English** (en) - Default
- 🇪🇸 **Español** (es) - Spanish

Language selection persists to localStorage and auto-detects browser settings.

## Usage Patterns

### Multiple Namespaces
```tsx
import { useTranslation } from 'react-i18next';

function ManualComponent() {
  const { t } = useTranslation(['common', 'manual']);
  
  return (
    <div>
      <h1>{t('manual:cover.title')}</h1>
      <p>{t('manual:cover.intro1')}</p>
      <button>{t('common:actions.close')}</button>
    </div>
  );
}
```

### Interpolation
```json
// In translation file:
{ "welcome": "Welcome, {{name}}!" }
```
```tsx
// In component:
{t('welcome', { name: playerName })}
```

### Pluralization
```json
{
  "items": "{{count}} item",
  "items_plural": "{{count}} items"
}
```
```tsx
{t('items', { count: itemCount })}
```

### Default Values
```tsx
{t('some.missing.key', { defaultValue: 'Fallback text' })}
```

## Adding Translations

### 1. Add to English
Edit `src/locales/en/common.json` or `src/locales/en/manual.json`:

```json
{
  "mySection": {
    "myKey": "My English text"
  }
}
```

### 2. Add to Spanish
Edit `src/locales/es/common.json` or `src/locales/es/manual.json`:

```json
{
  "mySection": {
    "myKey": "Mi texto en español"
  }
}
```

### 3. Use in Component
```tsx
const { t } = useTranslation('common');
<div>{t('mySection.myKey')}</div>
```

## Adding a New Language

### 1. Create Translation Files
```bash
mkdir -p src/locales/fr
cp src/locales/en/common.json src/locales/fr/common.json
cp src/locales/en/manual.json src/locales/fr/manual.json
# Translate content in the new files
```

### 2. Update i18n Config
Edit `src/config/i18n.ts`:

```typescript
import frManual from '../locales/fr/manual.json';
import frCommon from '../locales/fr/common.json';

const resources = {
  en: { ... },
  es: { ... },
  fr: {  // Add new language
    manual: frManual,
    common: frCommon,
  },
};
```

### 3. Update LanguageSwitcher
Edit `src/components/shared/LanguageSwitcher.tsx`:

```typescript
const languages = [
  { code: 'en', name: 'English', flag: '🇺🇸' },
  { code: 'es', name: 'Español', flag: '🇪🇸' },
  { code: 'fr', name: 'Français', flag: '🇫🇷' },  // Add new language
];
```

## Best Practices

### Use Nested Keys
```json
{
  "actions": {
    "play": "Play",
    "pass": "Pass",
    "challenge": "Challenge"
  }
}
```

### Keep Keys Descriptive
❌ Bad: `t('btn1')`  
✅ Good: `t('actions.play')`

### Listen for Language Changes
```tsx
useEffect(() => {
  const handleLanguageChange = (lng: string) => {
    console.log('Language changed to:', lng);
  };
  
  i18n.on('languageChanged', handleLanguageChange);
  
  return () => {
    i18n.off('languageChanged', handleLanguageChange);
  };
}, [i18n]);
```

## Migration Checklist

When adding i18n to existing components:

- [ ] Import `useTranslation` hook
- [ ] Replace hardcoded strings with `t()` calls
- [ ] Add translation keys to JSON files
- [ ] Test in both languages
- [ ] Update component documentation

### Example Migration

**Before:**
```tsx
function MyButton() {
  return <button>Start Game</button>;
}
```

**After:**
```tsx
import { useTranslation } from 'react-i18next';

function MyButton() {
  const { t } = useTranslation('common');
  return <button>{t('actions.startGame')}</button>;
}
```

## Language Detection

Languages are detected in this order:
1. **localStorage** - Previously selected language (`kred-language` key)
2. **Browser settings** - Navigator language
3. **Fallback** - English (en)
